# Identiband
Proyecto web Full Stack diseñado para la comercialización y gestión integral del producto Identiband.

## Descripción del Proyecto
Identiband es una solución integral que permite la gestión eficiente de productos y usuarios. El sistema incluye funcionalidades avanzadas como catálogo de productos, sistema de autenticación, carrito de compras, historial de pedidos y un panel administrativo para la gestión de datos.

## Características Principales
*   **Gestión de Inventario**: Control total sobre los productos, incluyendo el registro de pulseras NFC.
*   **Panel Administrativo**: Interfaz para visualizar gráficos de ventas y gestionar la base de datos SQL.
*   **Experiencia de Usuario**: Diseño responsivo enfocado en la usabilidad y flujo de compra.
*   **Funcionalidades de Sistema**: Registro de usuarios, favoritos, y creación de listas de invitados.

## Tecnologías Utilizadas
*   **Frontend**: (HTML, CSS, JS.)
*   **Backend/Base de Datos**: PHP y MySQL.
